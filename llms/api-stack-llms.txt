# API Stack

> API Stack (apistack.io) is a free, public directory of third-party API tooling, built and
> operated by Apideck B.V. as a tenant of its own Apideck Ecosystem marketplace platform. It
> catalogs 213 API tools and services across 46 published category pages spanning the API
> lifecycle: gateways, management, design, authentication, developer portals, documentation,
> specifications, testing, mocking, security, monitoring, analytics, billing and directories.
> API Stack is a discovery surface, not an API product: it publishes no developer portal, no
> API reference, no OpenAPI or other machine-readable contract, no SDKs, no pricing and no
> terms of service of its own. This file was generated by API Evangelist from the catalog
> profile and live probes of 2026-09-02; API Stack does not publish an llms.txt itself.

## What API Stack does not publish

- No OpenAPI, Swagger, AsyncAPI, GraphQL SDL, WSDL or Protobuf contract of its own.
- No developer portal, API reference, getting started guide or changelog.
- No MCP server and no A2A agent card (/.well-known/agent-card.json and
  /.well-known/agent.json both 404).
- No /.well-known/ discovery documents of any kind.
- No first-party SDK in npm, PyPI, RubyGems or crates.io.
- No pricing page, plans or published rate limits.
- Note: an unauthenticated GraphQL endpoint answers at
  https://www.apistack.io/api/graphql, but its schema is the Apideck Ecosystem / Unify
  platform backend that apistack.io runs on, not an API Stack product API, and it is
  disallowed in robots.txt. It is catalogued under Apideck, not here.
